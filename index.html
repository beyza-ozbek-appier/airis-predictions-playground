AIRIS Predictions Playground

Design templates, mockups, prototypes & specs for AIRIS Predictions — experimental. Two parallel iterations of the Predictions Listing prototype currently live here; see the note below for what changed between them.

Predictions Listing prototypes
v1 vs v2: v1 is the original prototype + spec (23-state dev switcher; spec covers 3 user flows and audits 24 error scenarios against the Design-System-Guideline rubric, driving 13 copy fixes back into the prototype). v2 adds the newer Behavior-Predictions-DS3.0 status/recommendation-warning feature set (5 statuses, "Refresh recommended" / "Retraining recommended") on top of the same prototype lineage, and adds a companion exhaustive user-flow inventory (25 flows, a cross-cutting states catalog, and a full Figma-coverage audit table) alongside its own PRD, README, and traceability matrix — documentation depth the v1 iteration doesn't have. Both are kept side by side rather than one replacing the other.
