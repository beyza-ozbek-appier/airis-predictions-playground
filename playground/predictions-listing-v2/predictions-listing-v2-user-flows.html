UF-05

Complete and validate the creation form

Partially implementedFigma-confirmed + 1 documented deviation
Goal: fill in a valid prediction and be able to save it.
Entry point
Wizard opened via UF-03/UF-04.
Preconditions
None.
Steps
  1. Enter prediction name (required) and optional description.
  2. Pick prediction type: Likely / Unlikely to perform.
  3. Set prediction window (7–90 days).
  4. Add ≥1 goal event (required), up to 10 total — counter shown as "(n/10)."
  5. Add constraints per goal event (attribute / operator / value / occurrence).
  6. Choose whether to schedule automatic refreshes (Yes/No).
  7. If Yes: pick One-time (single run date) or Recurring (Daily / Every 7–29 days / Monthly + Start date + End date).
  8. Save button enables once name + ≥1 goal event + (if scheduled) valid schedule fields are all present.
Decision / branch points
Schedule Yes/No; One-time vs. Recurring; Recurring frequency (Daily / Every-X-days / Monthly); goal-event count (1–10).
Alternative paths
Cancel at any point → discard, return to listing.
Exit / success condition
Save enabled and clicked → loading state → new row appears with status "Training" → toast.
Error / recovery paths
This "B" variant shows no inline field error messages — an explicit, earlier-approved product decision; the Save button's disabled state is the only validation signal (documented in the PRD, not a gap). Start date cannot be in the past; End date must be after Start date (both enforced, matching Figma Note 441:49634). Dates are limited to the client's contract period (matching Figma Note 354:32682, marked "✅" done in Figma).
Figma reference
"Create Prediction," 354:32145 ↗. Notes: goal-event max 10 (503:27603), Start/End date rules (441:49634), contract-period limiting (354:32682), Every-X-days range 7–29 (649:29353), timezone hint (506:28123).
